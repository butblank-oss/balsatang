# 발사탕 콘텐츠 가이드 — 작가처럼 쓰고, 데이터로 말한다

콘텐츠 전용 채팅(Claude)과 대표가 같이 보는 기준이다. 일하는 순서·도구는 docs/콘텐츠-인수인계.md. 글 한 편이 이 문서를 다 통과해야 발행한다.
목표는 하나 — **검색해서 들어온 보호자가 끝까지 읽고, 사료 상세까지 눌러 보게** 만드는 것.

---

## 1. 한 주의 흐름 (주 3편 · 화·목·토)

| 요일 | 할 일 | 결과물 |
|---|---|---|
| 월 | 키워드 조사 | 질문 후보 10개 + 고른 3개 |
| 화·목·토 전날 | 기획서 → 초고 → 사실 확인 | 초고 1편 |
| 발행일 오전 | 대표 승인 → 발행 | 사이트 콘텐츠 1편 |
| 4주 뒤 | 성과 확인 → 제목·훅 다시 쓰기 | 리라이트 목록 |

### 키워드는 세 곳에서 모은다
1. **네이버 데이터랩** — 검색어 트렌드(최근 3개월, 모바일). '강아지 사료 ○○' 묶음으로 오르는 말을 본다.
2. **구글 서치 콘솔** — 어드민 사용 분석 › 검색어(구글) 탭. 노출은 많은데 클릭이 적은 검색어 = 제목을 다시 쓸 후보.
3. **우리 사이트 검색** — 어드민 사용 분석 › 사료·검색 탭의 '결과 0건 검색'. 사람들이 찾는데 우리가 답을 못 한 것.

고르는 기준: ① 보호자가 실제로 묻는 **질문 문장**으로 바꿀 수 있는가 ② 발행된 사료 데이터로 답할 수 있는가 ③ 이미 있는 글과 겹치지 않는가.

## 2. 기획서 (글마다 1장)

```
검색어: 말티즈 사료 추천
질문으로 바꾸면: "말티즈 전용 사료를 꼭 먹여야 할까?"
읽는 사람: 말티즈 1~3살 보호자, 지금 사료를 바꿀까 고민 중
검색 의도: 비교 → 결정 (정보만 원하는 게 아니라 고르고 싶다)
첫 줄 훅 3안:
  1) 반전 — "말티즈 사료, 말티즈한테만 맞는 원료는 없었어요."
  2) 숫자 — "같은 1kg인데 가격이 8배. 라벨을 나란히 놨더니."
  3) 장면 — "사료 코너 앞에서 '말티즈' 글자에 손이 가는 순간."
다룰 사료(발행된 것만): [[비교 …]] 에 넣을 2~3개
결론 한 줄: 견종 이름보다 '첫 원료·탄수·주의성분' 세 줄이 먼저다
행동 유도: 비교하기 / 맞춤 추천 / 사료 상세
```

## 3. 쓰는 법 — 사람이 쓴 글처럼

### 제목 — 짧고, 궁금하게 (대표 피드백 2026-10-08)
검색 결과와 목록에서 제목은 한 줄로 끝나야 한다. **20자 안팎, 길어도 25자.** 설명은 요약(excerpt)에 맡긴다.

| ❌ 길고 설명적 | ✅ 짧고 궁금하게 |
|---|---|
| 100g에 11,225원 vs 1,100원, 비싼 사료는 뭐가 다를까 | 비싼 사료는 뭐가 다를까? |
| 사료 성분표, 이렇게 읽으면 됩니다 | 봉투 뒷면, 첫 줄만 보세요 |
| 눈물 자국, 사료가 원인일 수 있어요 | 강아지 눈물이 드디어 멈춘 이유 |
| — | 1kg에 10만 원, 그래도 먹이는 이유? |

제목 공식
- **결과를 먼저** — "○○이 드디어 멈춘 이유", "○○을 바꾸고 생긴 일"
- **숫자 + 의문** — "1kg에 10만 원, 그래도 먹이는 이유?"
- **반전 질문** — "그레인프리, 정말 답일까?"
- **금지 한 줄** — "이 원료가 첫 줄이면 다시 보세요"
- 제목에 사료 브랜드명을 넣어 깎아내리지 않는다. 숫자는 본문·카드에서 확인되는 것만.

### 스토리라인 — 기승전결 (대표 피드백 2026-10-08)
정보를 나열하지 말고, **한 보호자의 고민이 풀리는 이야기**로 끌고 간다. 가상 장면이어도 된다(아래 '가짜 경험담 금지' 지킬 것).

| 단계 | 하는 일 | 예: "강아지 눈물이 드디어 멈춘 이유" |
|---|---|---|
| **기** — 문제 장면 | 보호자가 겪는 구체적인 순간. 감정이 보이게 | 아침마다 눈가를 닦아도 다음 날 또 붉게 물드는 털 |
| **승** — 헛발질 | 흔히 해 보는 방법과 왜 안 됐는지 | 눈물 세정제, 비싼 영양제… 그래도 그대로 |
| **전** — 반전·발견 | 라벨을 펴 보니 보인 것. **여기서 데이터** (`[[비교 …]]`) | 사료 첫 줄과 원료 목록, 알러지 가능 원료 |
| **결** — 해결·행동 | 그래서 무엇을 보고 바꾸면 되는지 3가지 이하 + 다음 행동 | 원료 단순한 사료로 바꿔 보기, 수의사 상담 기준 |

- '전'에서 데이터를 보여 주기 전까지 독자가 궁금해야 한다. 앞에서 답을 다 주지 않는다.
- '결'은 약속이 아니라 **확인하는 방법**으로 끝낸다. "멈춥니다" ❌ → "이 세 가지를 보면 원인을 좁힐 수 있어요" ✅
- 결과를 단정하는 제목("멈춘 이유")은 본문에서 **"이런 경우가 있다"** 수준으로만 말한다. 의료 효과를 약속하지 않는다.

### 어투 — 토스 리서치형으로 통일 (대표 결정 2026-10-08)
레퍼런스: 토스증권 리서치 글. 화면도 같은 모양이다(#분류 → 큰 제목 → 에디터 인사 → 굵은 첫 문단 → 본문).

- **요약(excerpt)이 굵은 첫 문단이 된다.** 2~3문장. 독자를 부르며 시작해도 좋다 — "보호자님, 사료 봉투 뒷면 마지막으로 본 게 언제예요?" 끝은 "3분 만에 정리해 드릴게요" 처럼 이 글이 줄 것을 약속.
- **말끝:** "~거든요", "~는데요", "~예요/이에요", "~해 보세요". 친구한테 설명하듯. "~습니다" 는 쓰지 않는다.
- **문단은 2~3문장.** 한 문단에 할 말 하나.
- **소제목은 주장으로.** "탄수화물이란" ❌ → "표에 없어도, 탄수화물은 계산돼요" ✅. 두 줄로 끊어지는 길이(15~20자)가 좋다. 맨 앞에 ✅ 하나 정도는 괜찮다.
- **형광펜 `==…==`** — 그 문단의 핵심 한 문장에만. 한 문단 한 번, 글 전체 5~7번까지.
- **굵게 `**…**`** — 결론 문장이나 꼭 기억할 숫자. 형광펜과 같은 문장에 겹쳐 쓰지 않는다.
- **각주** — 숫자의 기준은 바로 아래 줄에 `*발사탕 데이터 기준(2026.10)` 처럼 별표로 시작해 작게.
- **마무리** — 마지막 소제목은 "그래서 이렇게 보세요" 류의 행동, 마지막 문단은 한 줄 결론.

### 첫 세 줄이 전부다
검색 결과에서 들어온 사람은 3초 안에 나간다. 첫 세 줄 안에 **궁금증**을 만들고, **이 글이 답을 준다**는 약속을 한다.

**훅 공식 (하나 골라 쓴다)**
- **반전** — 상식을 뒤집는다. "그레인프리가 무조건 좋을까? 20종을 까봤더니 아니었어요."
- **숫자** — 구체적인 숫자 하나. "100g에 11,225원 vs 1,310원."
- **장면** — 보호자가 겪는 순간. "눈물 자국을 닦다가 문득 사료 봉투를 뒤집어 봤어요."
- **질문** — 독자가 속으로 하던 질문을 그대로. "비싼 사료, 정말 그만큼 좋은 걸까요?"
- **오해 고백** — "저도 '닭고기가 첫 줄이면 좋은 사료'라고 믿었어요." (※ 아래 '가짜 경험담 금지' 지킬 것 — 발사탕 편집팀의 입장으로)

### 스토리 구조 (기본형)
1. **장면/훅** — 2~3줄
2. **왜 헷갈리나** — 보호자가 틀리기 쉬운 지점
3. **라벨을 펴 보면** — 실제 사료 2~3개로 보여준다 (`[[비교 …]]`)
4. **그래서 이렇게 보세요** — 체크 포인트 3개 이하
5. **한 줄 결론 + 다음 행동** — 비교하기 / 맞춤 추천 / 관련 글

### 문장 규칙
- 한 문단 2~3문장. 한 문장 40자 안팎. 길면 끊는다.
- 존댓말 '~요' 체. 친구에게 설명하듯. 가르치지 않는다.
- 소제목(`###`)은 질문이나 반전으로. "탄수화물의 정의" ❌ → "탄수화물, 표에 없는데 어떻게 알죠?" ✅
- 숫자는 사료 데이터에서 온 것만. 어림수로 바꾸지 않는다.
- 강조(`**굵게**`)는 한 문단에 한 번까지.

### 쓰지 않는 말 (AI 말투·광고 말투)
| 쓰지 않는다 | 대신 |
|---|---|
| ~에 대해 알아보겠습니다 / 살펴보겠습니다 | 바로 본론 |
| 결론적으로, 요약하자면, 마무리하자면 | "그래서 이렇게 보세요" |
| 다양한, 효과적인, 중요한 역할을 합니다 | 무엇이 어떻게 — 구체적으로 |
| 여러분, 반려인 여러분 | 보호자님 / 주어 생략 |
| 최고의, 완벽한, 무조건, 100% | 쓰지 않는다 |
| ~하는 것이 좋습니다 (반복) | "~해 보세요" 섞어 쓰기 |
| 이모지 남발, 느낌표 연속 | 한 글에 두세 개까지 |
| ~습니다 / ~합니다 | ~예요 / ~거든요 / ~는데요 |

## 4. 사료 사진·카드 쓰는 법

제조사 제품 사진을 따로 내려받아 글에 크게 붙이지 않는다(저작권). 대신 **사이트 사료 카드**를 끼운다 —
사이트가 이미 쓰는 카탈로그 썸네일을 같은 방식으로 보여 주고, 누르면 그 사료 상세로 간다.

본문에 **한 줄을 통째로** 아래처럼 쓴다. id 대신 '브랜드 + 이름'을 적어도 된다.

```
[[사료 지위픽 에어드라이 고등어&양고기]]
[[사료 뉴트리나 건강백서 말티즈, 로얄캐닌 독 미니 인도어 어덜트]]
[[비교 지위픽 에어드라이 고등어&양고기, 로얄캐닌 독 미니 인도어 어덜트, 뉴트리나 건강백서 말티즈]]
[[대결 아카나 시니어, 로얄캐닌 미니 인도어 시니어]]
```

- `[[사료 …]]` — 사진·브랜드·이름·주의성분·100g당 가격 카드. 쉼표로 여러 개.
- `[[비교 …]]` — 2~3개를 나란히: 첫 원료 / 조단백 / 탄수화물(건물 기준 추정) / 주의성분 / 100g당.
- `[[대결 A, B]]` — 두 사료 카드 + **'비교 화면에서 상황별로 보기'** 버튼. 누르면 두 사료를 비교함에 담고 비교 화면(상황별 판단)으로 간다. 'A vs B' 글의 마지막 행동 유도로 쓴다. 본문에 상황별 결과를 옮겨 적을 땐 비교 화면 문구와 똑같이.
- 숫자는 **카드가 데이터에서 직접 읽는다**. 본문에 같은 숫자를 또 쓸 땐 카드와 똑같이.
- 발행되지 않은 사료는 카드가 안 뜬다 — 없는 사료를 쓰지 않는다.
- 한 글에 카드·비교표는 3개까지. 글보다 카드가 많으면 카탈로그가 된다.

## 5. 사실 확인 체크리스트 (발행 전 전부 ✅)

**데이터**
- [ ] 글에 나온 숫자(단백질·탄수·가격·주의성분 수)가 사이트 사료 상세와 같다
- [ ] 원료 이름은 라벨 표기 그대로다 (다른 말로 바꾸지 않았다)
- [ ] 비교한 사료는 모두 발행된 사료다

**표현 (법·신뢰)**
- [ ] 질병을 고친다·낫는다·예방한다·치료한다 같은 말이 없다 (수의사법·사료관리법 표시 기준)
- [ ] 처방식은 "수의사와 상담" 문장이 있고, 효과를 우리 말로 새로 쓰지 않았다
- [ ] 특정 사료를 '나쁜 사료'로 단정하지 않았다 — '주의성분'은 '확인해 볼 점'이라고 설명했다
- [ ] **가짜 후기·가짜 경험담이 없다.** 보호자 장면은 "예를 들어"·"이런 순간" 처럼 가상임이 드러나게 쓴다. 실제 사람·후기를 지어내지 않는다
- [ ] 구매 링크가 있는 글은 쿠팡 파트너스 고지가 화면에 보인다 (사이트 하단에 상시 표시됨)

**읽기**
- [ ] 첫 세 줄에 훅이 있다
- [ ] 소제목만 읽어도 흐름이 보인다
- [ ] 마지막에 다음 행동(비교·맞춤 추천·관련 글)이 있다
- [ ] '쓰지 않는 말' 표에 걸리는 말이 없다

## 6. 성과 보고 다시 쓰기

어드민 › 사용 분석
- **여정·이탈** 탭 — '많이 읽은 글', 글 다음에 사료 상세로 갔는지
- **검색어(구글)** 탭 — 그 글 주소의 노출·클릭·순위

4주가 지나도 클릭률이 2% 미만이면 **제목과 첫 세 줄만** 다시 쓴다. 본문은 데이터가 바뀌었을 때만 고친다.
사료 정보가 바뀌면 카드 숫자는 저절로 바뀌지만, 본문에 직접 쓴 숫자는 사람이 고쳐야 한다 — 그래서 본문 숫자는 최소로.
