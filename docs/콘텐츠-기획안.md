## 0. 숏폼 공식을 글로 옮기면

| 릴스·유튜브 공식 | 발사탕 글에서는 |
|---|---|
| 3초 훅 | 제목 20자 + 첫 줄에 숫자·반전·장면 하나 |
| 오픈 루프("끝까지 보면…") | 답은 '전'에서. 첫 문단에 "마지막에 한 줄 공식을 드릴게요" 같은 약속 |
| 시리즈·클리프행어 | 편마다 끝에 **다음 편 예고 한 줄**. "다음 편: 주의성분 15종의 정체" |
| 고정 코너(요일 포맷) | 화·목·토에 코너를 고정 → 보호자가 "목요일엔 Q&A" 로 기억 |
| 고정 캐릭터 | 대표 캐릭터가 매 글 첫 줄·마지막 줄에 등장 (3장) |
| 댓글 질문 → 다음 영상 | 사이트 '결과 0건 검색'·서치 콘솔 검색어를 Q&A 질문으로 |
| 퀴즈·맞히기 | 짧은 글에서 "이 라벨, 첫 줄이 뭘까요?" → 답은 카드로 |
| 숫자 리스트 | "21종을 다 까 봤더니" 처럼 전수조사 숫자 |

지키는 선은 그대로다 — 숫자는 데이터에서만, 가짜 경험담 없음, 의료 효과 약속 없음, 특정 사료를 '나쁜 사료'로 단정하지 않음.

## 1. 주간 코너 (주 3편 + 월 1편)

| 요일 | 코너 | 길이 | 예 |
|---|---|---|---|
| 화 | **심층 시리즈** | 3~4분 | 라벨 해부학 2화 |
| 목 | **보호자 Q&A** | 1~2분 | "개봉한 사료, 얼마나 둬도 돼요?" |
| 토 | **짧은 일상 · 퀴즈** | 30초 | 오늘의 원료 한 줄 / 라벨 퀴즈 |
| 월 1회 | **발사탕 이야기** | 3분 | 왜 만들었나 → 이후 '만드는 사람들의 노트' |

## 2. 심층 시리즈 후보 (하나 이상 고르기)

### A. 라벨 해부학 (5화) — 추천 1순위
봉투 뒷면을 다 읽을 수 있게 되는 시리즈. 기존 글('봉투 뒷면, 첫 줄만 보세요')이 0화 역할.
1. 보장성분표의 숫자는 '최소'와 '최대'다 — 조단백 26% 이상의 진짜 뜻
2. 표에 없는 숫자, 탄수화물을 직접 계산해 보기 (건물 기준까지)
3. 주의성분 15종의 정체 — 하나씩 이름 풀이
4. 같은 재료, 다른 이름 — 쪼개 적기·괄호 속 원료 찾기
5. 내 사료를 직접 채점하기 — 발사탕 점수 공식 공개

### B. 21종 전수조사 (4화) — 데이터가 무기
발행된 사료 21종(라벨 있는 18종)을 전부 펴 본 결과. 예고용 숫자는 이미 확인됨.
1. 첫 줄이 곡물인 사료는 18종 중 6종
2. 탄수화물 순위 — 16% 이하 2종, 47% 넘는 6종 (회분까지 뺀 새 계산, 2026-10-09)
3. 100g당 140원부터 11,454원까지 — 가격대별로 달라지는 것
4. 주의성분 0종인 사료는 단 2종 — 그 둘의 공통점

### C. 대결 시리즈 (편마다 `[[대결]]` 버튼)
1. 다이어트 사료 대결 — 로얄캐닌 라이트 웨이트 케어 vs 아카나 라이트앤피트
2. 관절 사료 대결 — 건강백서 건강한 관절 vs 밥이보약 튼튼한 관절
3. 소형견 실내견 대결 — 건강백서 말티즈 vs 로얄캐닌 미니 인도어 어덜트
4. (발행된 시니어 편이 0화)

### D. 그거 사실 아니에요 (오해 깨기, 6화)
"곡물 = 알러지", "비싼 사료 = 좋은 사료", "시니어 = 저단백", "처방식 = 미리 먹이면 좋다",
"닭고기 첫 줄 = 고기 사료", "그레인프리 = 저탄수" — 기존 글의 반전을 짧고 세게 다시 쓴다.

## 3. 대표 캐릭터 — 안 3개 (이름·모습은 대표가 정함)

캐릭터 규칙: 라벨을 읽어 주는 역할까지만. 진단·치료 말은 하지 않고 "수의사와 상담" 은 그대로.

| 안 | 콘셉트 | 말버릇·코너 |
|---|---|---|
| ① 라벨 탐정 | 돋보기를 든 강아지 탐정. 매 글이 '사건 파일' | "첫 줄부터 수상한데요?" / 코너 '오늘의 사건' |
| ② 라벨 히어로 | 망토 두른 히어로. 필살기 '첫 줄 스캔' | "보호자님, 제가 펴 볼게요!" / 코너 '히어로 출동' |
| ③ 편집장 = 대표님 | 대표님을 그린 캐릭터. 창업 스토리와 바로 이어짐 | "제가 직접 까 봤어요" / 코너 '편집장 노트' |

이미지가 필요하면 그림은 따로 만들어야 한다(사진·일러스트). 글 표지는 지금도 색+아이콘으로 자동 생성된다.

## 4. 보호자 Q&A 후보 (목요일)

1. 사료 바꾸고 변이 물러요. 괜찮은 건가요?
2. 개봉한 사료, 얼마나 둬도 돼요?
3. 사료를 물에 불려 줘도 되나요?
4. 두 사료를 섞어 먹여도 되나요?
5. 간식은 하루에 얼마까지?
6. '해외 성분표 기준' 배지는 뭐예요?
7. 주의성분 0종이면 무조건 좋은 사료인가요?
8. 발사탕 점수에 왜 가격도 들어가요?
9. 말티즈 전용 사료, 꼭 먹여야 하나요?
10. 처방식엔 왜 점수가 없어요?

→ 네이버 데이터랩이 연동되면 실제 검색량 순으로 다시 고른다.

## 5. 짧은 일상·퀴즈 후보 (토요일, 30초)

- **오늘의 원료 한 줄** — "비트펄프, 왜 들어 있을까?" (카드 1개)
- **라벨 퀴즈** — 첫 줄만 보여 주고 "어느 사료일까요?" → 답은 카드
- **100g당 가격 맞히기** — 둘 중 비싼 쪽은?
- **봉투 앞면 번역기** — '홀리스틱', '휴먼그레이드' 같은 말이 라벨에선 무엇인지
- **이번 주 새로 올라온 사료** — 새로 발행된 사료 한 줄 소개

## 6. 개발 채팅에 부탁할 것 (고른 것만)

| 필요 | 왜 |
|---|---|
| 글 객체 `series: {id, no}` + 글 끝 '다음 편/이전 편' 버튼 | 시리즈 정주행 |
| 목록에 '짧은 글'·'Q&A' 분류 칩 | 코너별로 모아 보기 |
| 캐릭터 이미지 자리(글 첫머리 말풍선) | 캐릭터 고정 등장 |
| (선택) 퀴즈 접기 문법 `[[정답 …]]` | 눌러야 답이 보이게 |

## 7. 창업 스토리 질문지 → 대표 답변 대기

1. 발사탕을 만들기로 마음먹은 **그날**, 어떤 일이 있었나요?
2. 키우는 아이가 있다면 이름·견종·나이, 그리고 사료 때문에 고민했던 순간은?
3. 사료를 고르다 가장 답답했던 건 무엇이었나요?
4. 직접 라벨을 펴 보고 처음 놀랐던 점은?
5. 왜 '점수'와 '출처'에 이렇게 엄격하게 만들었나요?
6. 발사탕이라는 이름은 어떻게 지었나요?
7. 보호자가 발사탕을 쓰고 나서 어떻게 달라지면 좋겠나요?
8. 글에 실명·사진을 써도 되나요? (안 되면 '대표 ○○'처럼)
