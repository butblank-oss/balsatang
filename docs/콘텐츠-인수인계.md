# 콘텐츠 전용 채팅 — 인수인계

이 문서는 **콘텐츠 전용 채팅**(Claude)이 처음 읽는 문서다. 개발·사료 수집은 다른 채팅에서 한다.
글을 어떻게 쓰는지는 [`콘텐츠-가이드.md`](콘텐츠-가이드.md), 무엇을 근거로 쓰는지는 [`DATA-POLICY.md`](DATA-POLICY.md).

---

## 대표님과 일하는 방식 (꼭 지킬 것)
- 답은 **한국어**, 쉬운 말로. 결론은 간단히, **대표님이 할 일은 바로가기 링크까지 붙여 상세히**.
- 방향을 정할 일이 생기면 스스로 정하지 말고 **먼저 물어본다**. 물을 때 설명 길이(간단/상세)·어떤 전문가 관점·어떤 모델이 맞는지도 함께 확인한다.
- **발행은 대표님이 "발행해" 라고 한 글만.** 초고는 미리보기 이미지로 보여 주고 기다린다.
- 키·토큰·비밀번호를 채팅에 받지 않는다. 필요하면 환경 설정의 비밀값으로 넣어 달라고 안내한다.
- PR 은 직접 만들고 직접 머지해도 된다(대표 승인). 단, 글 발행 PR 은 "발행해" 를 받은 뒤에.

## 할 일 (첫 작업)
1. **시범 글 다시 쓰기** — `data/content-drafts/price-gap.js`.
   대표 피드백: 톤은 좋다. 제목을 짧게("비싼 사료는 뭐가 다를까?"), **기승전결을 더 탄탄하게**.
2. **기존 글 10편 전부 새 기준으로 다시 쓰기** — `articles.js`.
   - 제목: 20자 안팎 훅 (가이드 3장 '제목')
   - 본문: 기승전결 + 발행된 사료로 `[[사료 …]]`·`[[비교 …]]` (글마다 1~3개)
   - `id` 는 **바꾸지 않는다** (주소 `#/글/<id>` 와 검색용 페이지 `/content/<id>/` 가 이미 색인돼 있다)
   - 사실(숫자·원료·주의성분 설명)은 기존 글과 사료 데이터를 벗어나지 않는다
3. 다 쓰면 **미리보기 이미지**(폰 390px)로 대표님께 보여 주고 "발행해" 를 기다린다.
4. 그 다음부터 **주 3편**(화·목·토) — 정기 알림이 오면 가이드 1장 흐름대로.

## 저장소 지도
| 파일 | 무엇 |
|---|---|
| `articles.js` | 발행된 글 목록 `const ARTICLES = [ {id, cat, ico, title, excerpt, match?, body}, … ]` |
| `data/content-drafts/*.js` | 발행 전 초고 (사이트가 읽지 않음) |
| `app.js` `mdToHtml` · `mdEmbed` | 본문 문법: 빈 줄=문단, `### `=소제목, `- `=목록, `1. `=번호, `> `=강조 상자, `**굵게**`, 한 줄 `[[사료 브랜드 이름, …]]` / `[[비교 A, B, C]]` |
| `data.js` | 발행된 사료(FOODS)·상세(DETAIL). 카드·비교표 숫자는 여기서 읽는다 |
| `scripts/build-pages.mjs` | 검색용 정적 페이지. main 에 머지되면 GitHub Actions 가 알아서 다시 만든다 — 직접 돌려 커밋하지 않는다 |
| `index.html` | 글을 바꾸면 `articles.js?v=…` 숫자를 올려 캐시를 깬다 |

- `ico` 는 화면에 있는 아이콘 이름(예: microscope, ban, dna, droplet, coins, book). 모르면 기존 글 것을 쓴다.
- `match` 는 글 아래 '관련 사료' 자동 매칭. 본문에 카드를 넣었다면 없애도 된다(중복).

### 미리보기 만드는 법
로컬 서버(`python3 -m http.server`)로 사이트를 띄우고 Playwright(크로미움 설치됨)로
`ARTICLES` 에 초고를 넣은 뒤 `go('article', {articleId})` → 390px 전체 화면 캡처.

### 확인
- `npm run -s qa` — 화면·한글·디자인 검사 전 묶음 (발견 0건이어야 머지)
- 글 속 사료 이름이 틀리면 카드가 조용히 빠진다 → 미리보기에서 카드 개수를 꼭 센다

## 키워드 도구
- **네이버 데이터랩** — `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` 환경 변수로 호출 (검색어 트렌드 API).
  환경에 없으면 대표님께 환경 설정 비밀값으로 넣어 달라고 안내하고, 그동안은 웹 검색으로 대신한다.
- **구글 서치 콘솔** — 어드민 사용 분석 › 검색어(구글) 탭 (브라우저 로그인). 채팅에서는 직접 못 읽으니 대표님께 캡처를 부탁한다.
- **사이트 0건 검색** — 어드민 사용 분석 › 사료·검색 탭.
